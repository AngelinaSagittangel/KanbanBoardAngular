# Kanban Board

## Описание проекта

- Веб-приложение Kanban Board — fullstack-платформа для управления задачами, разработанная с использованием Angular и Node.js. Приложение взаимодействует с backend через API и включает систему авторизации, управление досками, колонками и карточками задач, назначение исполнителей, комментарии, уведомления и другие интерактивные возможности.

> **Цель проекта**
>
> Создать полноценное fullstack-приложение для организации рабочего процесса и на практике отработать разработку на Angular, проектирование REST API, работу с базой данных PostgreSQL, авторизацию, управление состоянием приложения и обмен данными в реальном времени.

## Ключевые возможности

- **Авторизация и регистрация.** Реализована система регистрации и входа пользователей с разграничением доступа к защищённым разделам приложения.
- **Управление досками.** Создание и организация рабочих пространств для управления задачами.
- **Колонки и карточки.** Создание, редактирование и удаление колонок и карточек, а также организация задач по этапам выполнения.
- **Управление задачами.** Добавление описаний, меток и сроков выполнения, назначение исполнителей и отслеживание статуса задач.
- **Drag and drop.** Перемещение карточек между колонками для удобного управления рабочим процессом.
- **Комментарии.** Возможность обсуждать задачи непосредственно в карточках.
- **Совместная работа.** Поддержка участников досок и разграничение прав доступа в зависимости от роли пользователя.
- **Уведомления.** Информирование пользователей о событиях, связанных с задачами и совместной работой.
- **Поиск.** Поиск карточек по содержимому с учётом текущей доски.
- **Обновления в реальном времени.** Использование WebSocket для обмена событиями между подключёнными клиентами.
- **Управление состоянием.** Использование Angular Signals для реактивного обновления интерфейса и состояния компонентов.
- **Работа с базой данных.** Хранение пользователей, досок, участников, задач, комментариев и уведомлений в PostgreSQL с использованием Prisma ORM.
- **Обработка ошибок и обратная связь.** Отображение результатов пользовательских действий и обработка ошибок при работе с API.
- **Переиспользуемые компоненты и сервисы.** Разделение логики приложения на компоненты, сервисы и отдельные модули для упрощения поддержки и развития проекта.

## Стек технологий

- **Frontend:** Angular, TypeScript.
- **Управление состоянием:** Angular Signals.
- **Маршрутизация:** Angular Router.
- **Стили:** SCSS.
- **Backend:** Node.js, Express, TypeScript.
- **API:** REST API.
- **База данных:** PostgreSQL.
- **ORM:** Prisma.
- **Обмен данными в реальном времени:** WebSocket (`ws`).
- **Инструменты разработки:** npm, Git, GitHub.

## Запуск проекта

### Backend

```bash
cd backend
npm install
```

- Создайте файл .env в папке backend и укажите строку подключения к PostgreSQL:
```bash
DATABASE_URL="postgresql://USER:PASSWORD@localhost:5432/kanban_db"
```

-Примените миграции базы данных и сгенерируйте Prisma Client:
```bash
npx prisma migrate deploy
npx prisma generate
```
-Запустите сервер:
```bash
npm run dev
```
### Frontend

-В отдельном терминале из корневой папки проекта:
```bash
cd frontend
npm install
ng serve -o
```
